Add an optional remote MCP server, ``huckleberry-mcp`` (``mcp`` extra), for Claude custom connectors. It serves Streamable HTTP with Clerk OAuth sign-in through FastMCP and an email allowlist, or stdio for local clients. Tools cover sleep, nursing, bottle, pump, activity, solids, diaper, potty, growth, temperature and medicine, plus history listing, edit and delete. Configuration comes from the environment and from ``.config/.env`` in the working directory.
